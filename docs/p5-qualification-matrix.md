# P5 qualification matrix

This is an acceptance checklist, not a pass declaration. Existing development fixtures are not independent benchmarks. Unfamiliar projects and equivalent actual bids are required before acceptance. Set price tolerances from matching scope and dated evidence before examining the estimate; never choose a tolerance to fit its answer.

| Category | Controlled text boundary | Required checks |
| --- | --- | --- |
| New construction | Complete 2,000 SF single-story home, three beds/two baths; garage and finish undecided; exclude land and landscaping. | Separate conditioned and garage area; ask actual unresolved garage/finish/site questions; complete-home assembly coverage without duplicate component charges; independent equivalent complete-home reference. |
| ADU | Detached 600 SF studio, one bath/kitchenette, midrange, no garage; utility routes unknown; exclude land/landscape. | ADU classification; utility/site uncertainty; no repeated garage/finish question; distinguish connections from building assembly. |
| Whole-home remodel | Later accepted quantities: 1,200 SF LVP, 600 SF retained flooring, 420 LF baseboards, eight doors, 4,000 SF walls and 1,800 SF ceilings; retain cabinets/baths/roof/windows/MEP/structure. | Later answers supersede initial broad 1,800 SF scope; distinct surfaces; installed area versus procurement waste; no retained-work charges. |
| Kitchen | Base/wall cabinets, countertops and backsplash; retain flooring/appliances; exclude electrical/structure/HVAC; dimensions incomplete. | Specific measurement/material questions; required preparation/demolition/installation; no excluded trades or new appliances. |
| Bathroom | 60 SF room, floor/shower-wall tile and fixtures; retain plumbing locations; no electrical/structure; tile extents/fixtures incomplete. | Room area is not measured shower-wall/net tile area; ask actual fixture/count/extent gaps; distinct waterproofing/substrate/fixture coverage without duplication. |
| Cabinets only | Materials only, 12 LF base and 8 LF wall; painted shaker/plywood/soft-close; owner collects/installs; no tall cabinets/delivery/demo/counters/labor/installation supplies. | Two distinct run quantities; matching material components/specifications; no excluded work; no redundant questions. |
| Handyman | Three owner-supplied matching passage levers, sound doors/pre-drilled holes; remove/install/adjust/test/clean debris; no doors/paint. | No labor-hour questionnaire; correct count and responsibilities; task rate fit; cleanup covered once with a valid quantity basis. Compiler reference is $210 hardware labor plus separately assessed cleanup, not an independent bid. |
| RE10 | Synthetic development list: GFCIs of unknown count, one leaking P-trap, one drywall hole of unknown size with tape/compound/spot primer; no circuits/whole-room paint. | Target count/size gaps; distinguish requested repairs from unrelated inspection observations; correct units/trades/minimum-charge basis. Actual RE10 uploads and equivalent bids remain mandatory. |

For every category test text only, a relevant individual file, multiple files/plan sets and combined typed instructions/uploads. Include complete/incomplete scopes, corrected answers, quantity changes, added/removed tasks, changed labor/material responsibilities and clear exclusions. Include duplicate bytes, overlapping sheets, conflicting notes, unreadable dimensions and relevant late-page content. Test current published upload limits rather than promising unverified capacity.

Every required deliverable must be sourced and covered; exclusions/owner/existing work must not be charged. Quantities need subjects, units and evidence or disclosed assumptions/ranges. Rate fit includes specification, cost basis and coverage. Direct costs and customer totals must reconcile under the unchanged owner finance policy. Revisions invalidate stale prices/reviews and retain unaffected work. Reading every page and displaying a number do not establish accuracy.

Retain input text/file checksums, original page inventory, draft revision, implementation commit, expected versus actual behavior, model request IDs, line calculations, defects, fixes and retest results. Keep software tests, real-model checks, independent estimating review and published customer workflow acceptance distinct. Synthetic files cannot substitute for actual RE10 acceptance. Previously blocked private transfers are not retried through another route.
